# 数据备份与恢复方案

生产环境建议使用 PostgreSQL 托管服务的时间点恢复能力，并额外执行每日 `pg_dump --format=custom` 逻辑备份。备份文件必须加密、与生产主机隔离，并按企业合规要求设置保留周期。

恢复演练流程：

1. 在隔离的测试实例创建空数据库，禁止指向生产地址。
2. 使用 `pg_restore --clean --if-exists --no-owner` 恢复最近备份。
3. 执行 `alembic upgrade head`，确认数据库版本一致。
4. 检查租户、店铺、订单、库存流水、打印任务和审计日志数量。
5. 随机抽检订单金额、SKU 映射和运单关联；验证多租户查询隔离。
6. 记录恢复点、耗时、缺失数据窗口与校验结果，演练失败不得覆盖现有备份。

建议至少每季度进行一次恢复演练。仓库不内置生产账号或备份密钥，实际调度由部署环境的密钥管理和备份服务承担。
